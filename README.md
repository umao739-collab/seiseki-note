# せいせきノート

学校で一から運用する、成績のための Google Apps Script（Webアプリ）です。
単元×観点×配点 → 到達率 → A/B/C の型で、通知表・指導要録・GG までをつなぎます。

```
テストを登録（学期ごと）→ 点数を入れる → 学期の観点の評価（通知表）→ 1年間の評価・評定（指導要録）→ GGに貼る
```

## できること（版 2.0）

| 画面 | できること |
|---|---|
| 📚 テストの登録 | 学年・教科・学期ごとに、テスト（単元）の名前と観点ごとの配点を登録。「同じ学年のクラスにも反映」でほかのクラスに写せる |
| ✏️ 点数を入れる | 上の「評価の基準」（A になる ○%以上・C になる ○%未満）を担任が決め、その場で評価と人数（このクラス・学年のほかのクラス）が変わる。表はスプレッドシートのように入れる（Ctrl+V で Excel・GG から貼りつけ） |
| 🌸 学期の成績 | 左から GG の「教科等」と同じ並び（知・思・主・評定）。右に観点ごとの A・B・C の人数と、基準を変えたときの増減。「📋 GG用にコピー」で名前なしのまま GG に貼れる。評価できない子は ‐（GG には / で入る） |
| 📖 要録（1年間） | 学期の評価を組み合わせ表に当てて指導要録の観点の評価を出す。評定は「評定の表」（AAA→3・AAB→2…）で担任が決める。「📋 GG用にコピー」あり |
| 📄 個票・所見 | 学期ごと・1年間の個票（教科ごとの到達率のレーダーチャート、とくい・のびしろ・のびたところ、教科ごとの観点の到達率と学級平均、単元ごとの評価）。成績から見た所見の下書き（長さ・言い方を変えられる・全員分をいっきに）。1人・全員を A4 で印刷・PDF。「AIに頼む文」には名前・点数を入れない |
| 🔧 学校の設定 | 名簿マスターのリンクを貼って名簿を取り込む、担任・担当の割り当て |

## デザイン

「教室と黒板」。黒板の緑にチョークの文字、画面の中身はマグネットでとめた掲示物の紙、タブは色チョークのラベル。点数の表は読みやすさを優先して白い紙の時間割のような表。絵は文房具（リングノート・えんぴつ・色えんぴつ・三角定規。すべてオリジナル）。

## しくみと安全（ふりかえりシート 他校版と同じ考え方）

- Webアプリは「デプロイした人（アプリ管理者）として実行」。成績は、アプリ管理者のドライブの学校×年度ごとのスプレッドシートにだけ置き、だれとも共有しません。
- 本人は `Session.getActiveUser()` だけで決めます。教職員の名簿にいない人は断ります（拒否が既定）。
- 先生は担当のクラスだけ、設定担当（登録された人と、校長・教頭・教務主任）は自分の学校だけ。画面から来るクラスは、必ずサーバーで担当の一覧と照らし合わせます。
- 公開関数は `PUBLIC_FUNCTIONS` の一覧だけ。どれも `guard_` → `getContext_` の順で始まります（テストで確かめます）。
- シートには `escapeFormula_` を通してテキスト書式で書きます。画面では HTML を文字列で差しこみません。
- このリポジトリは公開されているので、メール・ファイルIDはコードに書かず、Script Properties に置きます（テストで確かめます）。

## 試し方

```bash
node tools/run-local-tests.js     # 安全のきまり・入力の検査・成績の計算
node tools/build-preview.js       # preview/index.html（作りものの名簿・点数で全画面を試せる）
```
