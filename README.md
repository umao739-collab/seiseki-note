# せいせきノート

学校で一から運用する、成績のための Google Apps Script（Webアプリ）です。
単元×観点×配点 → 到達率 → A/B/C の型で、通知表・指導要録・GG までをつなぎます。

```
テストを登録（学期ごと）→ 点数を入れる → 学期の観点の評価（通知表）→ 1年間の評価・評定（指導要録）→ GGに貼る
```

## できること（版 2.0）

| 画面 | できること |
|---|---|
| 📚 テストの登録 | 学年・教科・学期ごとに、テスト（単元）の名前と、観点ごとの配点を登録します。「同じ学年のクラスにも反映」ボタンで、ほかのクラスにも写せます（同じ名前のテストは配点をそろえます。写す先にしかないテストと点数は消しません） |
| ✏️ 点数を入れる | 上の「評価の基準」で、観点ごと・テストの評価の「A になる %（以上）」「C になる %（未満）」を担任が決めます。数字を変えると、表の評価と、このクラス・学年のほかのクラスの A・B・C の人数がその場で変わります。表はスプレッドシートのように入れます。矢印キー・Enter・Tab で移動、Excel・スプレッドシート・GG からのまとめた貼りつけ（Ctrl+V）、範囲のコピー（Ctrl+C）、もどす（Ctrl+Z）。到達率と単元の評価はその場で出ます |
| 🌸 学期の成績 | 観点ごとの到達率と A/B/C（通知表）。「主体的に学習に取り組む態度」は先生が入れます。計算の評価を変えたいときは打ちこむと先生の値（✎）が優先されます |
| 📖 要録（1年間） | 学期の評価を組み合わせ表に当てて、指導要録の観点の評価を出します。3年生以上は評定も出します。評定は「評定の表」（AAA→3・AAB→2…のように観点の組み合わせで決める。並びは関係なし）で、担任がクラスごとに決め、同じ学年に反映できます |
| 📋 GGに貼る | 校務支援システム GG の「教科等」の並び（知・思・主・評定）の表を出し、ボタン1つでコピーします（名前は入りません） |
| 🔍 入れわすれ | 点数が空いている子・「主体的」が空いているところを見つけます |
| 🔧 学校の設定 | 名簿マスターのリンクを貼って名簿を取り込む、担任・担当の割り当て、学年ごとの教科・観点と基準の初期値 |

## しくみと安全（ふりかえりシート 他校版と同じ考え方）

- Webアプリは「デプロイした人（アプリ管理者）として実行」。成績は、アプリ管理者のドライブの学校×年度ごとのスプレッドシートにだけ置き、だれとも共有しません。
- 本人は `Session.getActiveUser()` だけで決めます。教職員の名簿にいない人は断ります（拒否が既定）。
- 先生は担当のクラスだけ、設定担当（登録された人と、校長・教頭・教務主任）は自分の学校だけ。画面から来るクラスは、必ずサーバーで担当の一覧と照らし合わせます。
- 公開関数は `PUBLIC_FUNCTIONS` の一覧だけ。どれも `guard_` → `getContext_` の順で始まります（テストで確かめます）。
- シートには `escapeFormula_` を通してテキスト書式で書きます。画面では HTML を文字列で差しこみません。
- このリポジトリは公開されているので、メール・ファイルIDはコードに書かず、Script Properties に置きます（テストで確かめます）。

## 試し方

```bash
node tools/run-local-tests.js     # 安全のきまり・入力の検査・成績の計算
node tools/build-preview.js       # preview/index.html（作りものの名簿・点数で全画面を試せる）
```
